# Application Library Upgrade Guides

## Purpose

This repository contains instructions for updating our PHP applications to work with newer versions of third-party libraries that are compatible with PHP 8.3.

Each guide explains:

- Which library version has been selected.
- Why that version was chosen.
- Changes required to existing application code.
